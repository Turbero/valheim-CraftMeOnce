### CHANGELOG

## 1.1.0

Vendors update!

Added:
* A new hint button is available at vendors to see which items have not been acquired by the player yet
* A new field is available at vendors window showing how many items they have hidden to the player at that moment

Changed:
* Reworked config names and sections (delete .cfg and recreate if any trouble)

Fixed:
* Hint buttons position and size can be changed in-game from config file now
* Some descriptions in the config file

## 1.0.6

* Reworked "Show Exclamation" option into "Hint Mode" to be able to choose a new "Always" mode where the hint is always shown and the hint button is hidden (default = On)
* Workstation hint button and hint character of uncrafted recipes are now always both hidden at only-upgrade workstations, like the new Forge of Potential

## 1.0.5

* Recompiled for compatibility with 1.0

## 1.0.4

* Little adjustment of the gamepad hint position of the button to avoid hiding other hints

## 1.0.3

* Added support for controllers
* Couple of configuration entry names

## 1.0.2

* Added option to repair all items at once in one click at workstations.
* Exclamation button active by default now.

## 1.0.1

* Added tiny button with exclamation in the top left side of the crafting tab to enable/disable the !-mark at your choice. Position/size can be adjusted in .cfg file.
* Added option to change "!" for any other character in the .cfg file ("!" by default).
